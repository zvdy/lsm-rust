# Maintainers

This file lists the maintainers of lsm-rust. Maintainers review and merge
pull requests, triage issues, cut releases, and steer the project roadmap
as described in [GOVERNANCE.md](GOVERNANCE.md).

## Becoming a Maintainer

Consistent, high-quality contributions (code, reviews, triage) are the path
to maintainership. Existing maintainers nominate and approve new maintainers
as described in [GOVERNANCE.md](GOVERNANCE.md).
